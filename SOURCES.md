## Rights sources for the Paleologo three-book set

### Cheney & Light

- AMS book page: https://bookstore.ams.org/GSM/101
- AMS copyright/end matter: https://www.ams.org/books/gsm/101/gsm101-endmatter.pdf
- AMS rights/licensing: https://bookstore.ams.org/rights-licensing

The AMS notice permits ordinary fair use but says republication, systematic copying, or multiple reproduction requires an AMS license.

### Trefethen & Bau

- Trefethen author page with public front matter and Lectures 1–5: https://people.maths.ox.ac.uk/trefethen/text.html
- 1997 SIAM DOI: https://doi.org/10.1137/1.9780898719574
- SIAM platform terms: https://epubs.siam.org/page/terms
- SIAM permissions guidance: https://epubs.siam.org/author-handbook

The author-hosted samples are lawful public reading copies, but no redistribution license was found. SIAM's terms distinguish personal/educational downloading from publication or republication, which requires permission unless material is explicitly open-licensed.

### Golub & Van Loan

- Hopkins publisher page: https://press.jhu.edu/books/title/10678/matrix-computations
- Hopkins rights and permissions: https://www.press.jhu.edu/rights-permissions
- Hopkins institutional-repository policy: https://www.press.jhu.edu/rights-permissions/institutional-repository-use

Hopkins' limited repository allowance concerns authors posting parts of their own contributions. It is not a general license for third parties to mirror the book.

## Interpretation

A web-accessible PDF, scan, preview, institutional-login copy, author-hosted sample, or controlled-lending copy is **not** automatically a license to redistribute it from this repository.

A full-text mirror should be added only when one of these is preserved alongside it:

- an explicit open license permitting redistribution;
- an author/publisher statement granting redistribution;
- public-domain status that is actually established for the edition/material in question.

When that evidence is absent, preserve the lawful URL and write our own notes.

Original explanations, implementations, worked examples, experiments, bibliographic facts, and independently expressed mathematical facts/formulas/algorithms are the preferred repository material.

## Separate software/material licenses

Textbook companion code can have a different license from the book. In particular, the Cheney–Kincaid sites publish sample software separately. Check and record the exact code license before copying any companion program; book copyright and code license must not be conflated.
